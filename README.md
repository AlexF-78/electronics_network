# Electronics Network - Проект управления сетью электроники

## Описание проекта

Веб-приложение с API для управления сетью продажи электроники.
Сеть представляет собой иерархическую структуру из трех уровней:

- **Завод** (уровень 0)
- **Розничная сеть** (уровень 1)
- **Индивидуальный предприниматель** (уровень 2)

## Технологии

- **Backend**: Python 3.13, Django 6.0
- **API**: Django REST Framework 3.16+
- **База данных**: PostgreSQL 15
- **Пакетный менеджер**: Poetry
- **Фильтрация**: django-filter 25.2+
- **Конфигурация**: python-dotenv
- **Качество кода**: Black, Flake8, isort
- **Тестирование**: pytest, coverage.py 7.13+

## Установка

1. **Клонируйте репозиторий**:

   ```bash
   git clone <repository-url>
   cd electronics_network
   ```
2. **Установите зависимости Python с помощью Poetry**:

   ```bash
   poetry install
   ```
3. **Активируйте виртуальное окружение Poetry**:

   ```bash
   poetry shell
   ```
4. **Настройте базу данных PostgreSQL**:
   - Создайте новую базу данных с именем `electronics_network`.
   - Создайте файл `.env` на основе примера:

   ```bash
    cp .env.sample .env
   ```
   - Откройте `.env` и укажите реальные параметры подключения к вашей PostgreSQL (имя пользователя, пароль, хост).

5. **Примените миграции для создания таблиц в базе данных**:

   ```bash
   python manage.py migrate
   ```
6. **Создайте суперпользователя**:

   ```bash
   python manage.py createsuperuser
   ```
7. **Запустите сервер для разработки**:

   ```bash
   python manage.py runserver
   ```
8. **Откройте браузер и перейдите по адресу**:
   **`http://127.0.0.1:8000`**

## Админ-панель

Доступна по адресу `/admin/`

**Возможности:**
- **CRUD для всех моделей** — полное управление контактами, продуктами и звеньями сети
- **Фильтрация по городу** — быстрый поиск звеньев в конкретном населенном пункте
- **Ссылка на поставщика** — навигация к связанному поставщику одним кликом
- **Action для очистки задолженности** — выделите несколько узлов и очистите их долги за один шаг

## API

Доступно по адресу `/api/`

### Эндпоинты:

- **GET** `/api/node/` — получение списка всех звеньев сети с возможностью фильтрации
- **POST** `/api/node/` — создание нового звена (поля `name`, `node_type`, `contact` обязательны)
- **GET** `/api/node/{id}/` — получение детальной информации о конкретном звене
- **PUT/PATCH** `/api/node/{id}/` — полное или частичное обновление звена (поле `debt` доступно только для чтения)
- **DELETE** `/api/node/{id}/` — удаление звена из сети

## Модели данных
### Contact (Контакты)
- **Email** — электронная почта
- **Страна** — страна проживания/регистрации
- **Город** — населенный пункт
- **Улица** — название улицы
- **Номер дома** — номер строения

### Product (Продукты)
- **Название** — наименование продукта
- **Модель** — модель устройства
- **Дата выхода на рынок** — когда продукт поступил в продажу

### NetworkNode (Звено сети)
- **Название** — наименование звена сети
- **Тип звена** — выбор из: завод, розничная сеть, ИП
- **Контакты** — связь One-to-One с моделью Contact
- **Продукты** — связь Many-to-Many с моделью Product
- **Поставщик** — ссылка на другое звено сети (ForeignKey на себя)
- **Задолженность перед поставщиком** — денежная сумма с точностью до копеек
- **Дата создания** — автоматически заполняется при создании записи

### Фильтрация:

- **По стране**: `/api/node/?contact__country__icontains=Россия`
- **По типу узла**: `/api/node/?node_type=0`
- **По городу**: `/api/node/?contact__city__icontains=Москва`

### Права доступа:

- Доступ к API имеют только **активные сотрудники** (`is_staff=True`)
- Поле **`debt`** (задолженность) запрещено к изменению через API

## Иерархия сети

Каждое звено автоматически определяет свой уровень в иерархии на основе связи с поставщиком:

- **Уровень 0** — нет поставщика (завод)
- **Уровень 1** — поставщик является заводом (розничная сеть)
- **Уровень 2** — поставщик является розничной сетью (индивидуальный предприниматель)

### Определение уровня

Метод **`get_hierarchy_level()`** рекурсивно вычисляет уровень узла:
- Если у узла нет поставщика → уровень 0
- Если есть поставщик → уровень = уровень поставщика + 1
- Максимальный уровень ограничен 2 (индивидуальный предприниматель)

Пример:
- Завод (id=1, supplier=None) → уровень 0
- Розничная сеть (id=2, supplier=1) → уровень 1
- ИП (id=3, supplier=2) → уровень 2
