# Electronics Network

Проект управления сетью электроники

## 🚀 Установка

1. Клонировать репозиторий
2. Установить Poetry: `pip install poetry`
3. Установить зависимости: `poetry install`
4. Скопировать `.env.sample` в `.env`
5. Заполнить переменные в `.env`
6. Выполнить миграции: `python manage.py migrate`
7. Запустить сервер: `python manage.py runserver`
